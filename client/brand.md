# Brand

Last updated: 2026-10-22.

## Where it stands

- The live site (www.acnnewswire.com) looks and is built like the early 2010s: table layout, Bootstrap 2.2.2, jQuery 1.10.2, no mobile layout ([research note](../research/2026-10-22-homepage-accessibility-structure.md)).
- The new CMS and newsroom set the direction for the new look (below).

## Design direction for new work

- "Dated but confident": black, white and gray, driven by typography. No decorative color except ACN blue (Kris, Aug 2026).
- Custom CSS, no component libraries (Kris, Aug 2026, for the CMS).
- Familiar, utilitarian patterns over novelty ([decision 0003](../decisions/0003-design-for-familiarity.md)).

## Current messaging

- Page title: "Asian press release distribution - ACN Newswire". Meta description: real-time distribution to media, business and financial markets, in five languages (site, 2026-10-22).
- Weak points: the homepage has no headline (no `<h1>`) that says what ACN does; the description is buried in metadata.
