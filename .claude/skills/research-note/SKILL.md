# Research note

1. Copy `templates/research.md` to `research/YYYY-MM-DD-short-topic.md`. Put screenshots and source files in `research/files/` with the same date prefix.
2. Start with a **Method** line: what was looked at and how (sites read, searches, files or screenshots from the team).
3. Write findings in your own words. Give every fact its source (a link, "client said", "team screenshot") and mark guesses as guesses.
4. End with **What this means for the project** and **Next steps**.
5. Update the files that this changes: `client/` for facts about the client, `project/open-questions.md` for new questions, `project/status.md` if priorities moved.
6. Finish with the `session-log` skill.

Keep quotes from sources short; summarize instead of copying.
